# マナー道場

食事・職場・訪問・電話とメールの マナーを、お話と 絵を 見ながら 問題で 覚える アプリです。

**遊ぶ**: https://radevocal-bit.github.io/manners-dojo/

- 分野を 選ぶと お話が はじまります。答えると 道場の 先生が ひとこと 言い、「なぜ そうするか」が 出ます。
- まちがえた 問題は ブラウザが 覚えていて、「もう一度」で 解き直せます。
- 点数に あわせて 段位（見習い〜師範代）が 出ます。
- 分野ごとの さいこう点（正解率）も ブラウザが 覚えていて、はじめの 画面の 下に 出ます。

## 作り方

このアプリの プログラム（js/ の 中）は、パソコンの 中で 動く AI（ローカル LLM・gemma4 26B）が、1 歩ずつ 書きました。
仕様と 試験、絵と 問題の 多くは、別の AI（Claude）が 用意しました。

ネットに つながなくても、index.html を 開くだけで 動きます（外の 部品は 使っていません）。
