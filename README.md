# マナー道場

食事・職場・訪問・電話とメール・公共の場・冠婚葬祭・会議・お店・温泉旅館・病院・近所づきあい・飛行機・贈り物・図書館・美術館・映画館・エレベーター・公園・お祭り・カフェ・スポーツ観戦・プール・キャンプ場・動物園・海水浴のマナーを、お話と絵を見ながら問題で覚えるアプリです。

**遊ぶ**: https://radevocal-bit.github.io/manners-dojo/

- 分野を選ぶとお話がはじまります。答えると道場の先生がひとこと言い、「なぜそうするか」が出ます。
- まちがえた問題はブラウザが覚えていて、「もう一度」で解き直せます。
- 点数の画面の「○○をもう一度」で、同じ分野をはじめから解き直せます。
- 「腕だめし」で、全部の分野から10問をまぜて解けます（分野のさいこう点には入りません）。腕だめしのさいこう点も覚えて、ボタンに出ます。
- パソコンでは数字のキー（1・2・3）で答え、Enter でつぎへ進めます。
- 点数にあわせて段位（見習い〜師範代）が出ます。
- はじめの画面に「道場の進み」（全部の問題のうち、一度でも正解した数）が出ます。
- 「今日の1問」で、毎日ちがう1問を解けます（日づけで決まり、同じ日はみんな同じ問題）。
- 分野のボタンに、その分野で一度でも正解した問題の数（「正解 ○」）が出ます。
- 答えた日をブラウザが覚えていて、はじめの画面に「○ 日続けて練習中」が出ます。
- 分野ごとのさいこう点（正解率）もブラウザが覚えていて、はじめの画面の下に出ます。さいこう点をこえると、点数の画面に「新記録！」が出ます。
- はじめの画面に「つぎのおすすめ」のボタンが出ます（まだ解いていない分野か、さいこう点のいちばん低い分野）。押すとその分野がはじまります。
- 解いた分野のさいこう点の平均と、総合の段位も出ます。
- 点数の画面の下に「まちがえた問題」と正しい答え、「なぜそうするか」が出ます（ふりかえり）。

## 作り方

このアプリのプログラム（js/ の中）は、パソコンの中で動く AI（ローカル LLM・gemma4 26B）が、1歩ずつ書きました。
仕様と試験、絵と問題の多くは、別の AI（Claude）が用意しました。

ネットにつながなくても、index.html を開くだけで動きます（外の部品は使っていません）。
