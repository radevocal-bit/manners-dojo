# マナー道場

食事・職場・訪問・電話とメール・公共の場・冠婚葬祭・会議・お店・温泉旅館・病院・近所づきあいの マナーを、お話と 絵を 見ながら 問題で 覚える アプリです。

**遊ぶ**: https://radevocal-bit.github.io/manners-dojo/

- 分野を 選ぶと お話が はじまります。答えると 道場の 先生が ひとこと 言い、「なぜ そうするか」が 出ます。
- まちがえた 問題は ブラウザが 覚えていて、「もう一度」で 解き直せます。
- 点数の 画面の「○○を もう一度」で、同じ 分野を はじめから 解き直せます。
- 「腕だめし」で、全部の 分野から 10 問を まぜて 解けます（分野の さいこう点には 入りません）。
- パソコンでは 数字の キー（1・2・3）で 答え、Enter で つぎへ 進めます。
- 点数に あわせて 段位（見習い〜師範代）が 出ます。
- 分野ごとの さいこう点（正解率）も ブラウザが 覚えていて、はじめの 画面の 下に 出ます。さいこう点を こえると、点数の 画面に「新記録！」が 出ます。
- はじめの 画面に「つぎの おすすめ」の ボタンが 出ます（まだ 解いて いない 分野か、さいこう点の いちばん 低い 分野）。押すと その 分野が はじまります。
- 解いた 分野の さいこう点の 平均と、総合の 段位も 出ます。
- 点数の 画面の 下に「まちがえた 問題」と 正しい 答え、「なぜ そうするか」が 出ます（ふりかえり）。

## 作り方

このアプリの プログラム（js/ の 中）は、パソコンの 中で 動く AI（ローカル LLM・gemma4 26B）が、1 歩ずつ 書きました。
仕様と 試験、絵と 問題の 多くは、別の AI（Claude）が 用意しました。

ネットに つながなくても、index.html を 開くだけで 動きます（外の 部品は 使っていません）。
